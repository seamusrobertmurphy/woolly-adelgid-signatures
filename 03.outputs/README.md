# 03.outputs

Generated tables and figures. Committed, because the manuscript cites them and a fresh
clone must render without re-running the analysis.

Only outputs written by saved code belong here: a CSV produced by an ad-hoc terminal
snippet cannot be cited until the code that made it is checked into `05.scripts/` or the
manuscript. Keep files small; anything large enough to strain git belongs on the external
drive with a summary CSV here in its place.

`figures/` holds rendered PNGs at their publication resolution, each one also produced by
a labelled manuscript chunk so that the committed file and the rendered file cannot
diverge.
